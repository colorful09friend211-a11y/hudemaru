# ふでまる｜書道部運営アプリ

書道部の活動・部員管理・連絡・アンケートなどをまとめて管理するWebアプリです。

## 🌸 主な機能

- 部活動のお知らせ・予定の確認
- 部員向けポータル
- アンケート
- 欠席連絡
- 各種申請
- 管理者機能（パスワード保護）
- キャラクター「ふでまる」のアニメーション

## 🌐 公開サイト

GitHub Pagesを利用して公開しています。

（ここに公開URLを記載）

## 使用方法

公開サイトにアクセスすると部員向けページを利用できます。

管理機能を利用する場合は管理者パスワードが必要です。

## 使用技術

- HTML
- CSS
- JavaScript

## 注意事項

現在、アプリ内のデータは利用しているブラウザに保存される仕様です。

端末やブラウザが異なる場合、データは共有されません。

個人情報や機密情報の取り扱いには注意してください。
