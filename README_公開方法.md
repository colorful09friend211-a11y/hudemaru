# ふでまる v11 公開準備版

## 今回の調整
- ふでまるをサイト上に常時表示
- ふでまるが定期的に笑顔で跳ねたり、手を振るアニメーションをする
- アンケート・欠席連絡・費用申請などの操作完了時にもリアクション
- favicon（サイトアイコン）を表示しない設定
- 部員ポータルはログインなし、管理者モードはパスワード入力を維持

## 無料で公開する方法（GitHub Pages）
1. GitHubで新しいPublicリポジトリを作成（例：`fudemaru-club`）。
2. このHTMLをリポジトリにアップロードし、ファイル名を `index.html` に変更。
3. リポジトリの Settings → Pages を開く。
4. Build and deployment の Source を `Deploy from a branch`、Branch を `main` / `root` にして保存。
5. 数分後、表示された `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開。

## 重要な注意
このアプリは現在、データをブラウザの localStorage に保存するローカル試作版です。
- 公開URLを閲覧する人は誰でもサイトを開けます。
- データは閲覧者ごとの端末・ブラウザに保存され、みんなで同じデータを共有できません。
- 管理者パスワードはブラウザ内で判定される方式で、本番用の安全な認証ではありません。ソースを見れば初期パスワードや認証処理を解析できる可能性があります。
- 部員名・学籍番号・会計・レシートなど個人情報を入れたまま公開しないでください。共同利用や安全な管理にはサーバー・認証・データベースの構築が必要です。
